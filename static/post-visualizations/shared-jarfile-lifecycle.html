closed된 Shared JarFile이 Spring Boot 클래스 로더 캐시에 남는 과정

  1. Spring Boot 클래스 로더와 Reflections가 Shared JarFile A 인스턴스를 함께 사용합니다.
  2. 캐시 등록 전에 Reflections가 A 인스턴스를 닫습니다. 캐시에 A 인스턴스가 없어 제거하지 못합니다.
  3. 닫힌 A 인스턴스가 뒤늦게 캐시에 등록되어 남을 수 있습니다.
  4. 이후 해당 Jar의 클래스 로딩이 ClassNotFoundException으로 실패할 수 있습니다.
